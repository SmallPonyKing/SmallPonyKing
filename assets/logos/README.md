# Logo sources

The six SVGs in this directory are from the Lobe Icons project. The upstream MIT license is included in LICENSE. Original brand names and artwork remain owned by their respective owners. Logos identify companies and tools in an AI-landscape overview; they do not indicate employment, endorsement, or certifications.

Source repository: https://github.com/lobehub/lobe-icons

Original files:
- packages/static-svg/icons/openai.svg
- packages/static-svg/icons/claude-color.svg
- packages/static-svg/icons/gemini-color.svg
- packages/static-svg/icons/deepseek-color.svg
- packages/static-svg/icons/huggingface-color.svg
- packages/static-svg/icons/ollama.svg

Short descriptions reference these first-party sources:
- https://openai.com/
- https://claude.com/product/overview
- https://ai.google.dev/gemini-api/docs
- https://github.com/deepseek-ai/DeepSeek-R1
- https://huggingface.co/brand
- https://ollama.com/

Brand-colored SVG paths are kept intact in the generated landscape. Monochrome icons inherit a readable foreground color for the selected theme. Local copies keep profile rendering independent of image widget services.
